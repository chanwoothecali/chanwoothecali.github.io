# chanwoothecali.github.io

Basic starter template for a GitHub Pages personal site.

## Files

- `index.html`: landing page
- `styles.css`: shared styles

## Run locally

Open `index.html` in a browser, or use any simple static server.

## Deploy

Push to the `main` branch of this repository and GitHub Pages can serve it as `https://chanwoothecali.github.io/`.
